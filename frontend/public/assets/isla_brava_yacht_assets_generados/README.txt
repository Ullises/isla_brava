Recursos generados visualmente a partir de la referencia.
Las fotos son escenas SINTÉTICAS y no fotografías verificadas de las embarcaciones anunciadas.
No se deben usar para representar el modelo real sin validación.
Las imágenes son recortes de una composición generada a 1536 x 1024; por tanto su
resolución nativa sigue siendo limitada, aunque no provienen de las miniaturas originales.
Los SVG son iconos vectoriales recreados y se pueden estilizar con currentColor.
Para imágenes de catálogo HD auténticas se necesitan las fotografías originales.
